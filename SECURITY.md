# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/pablo-arroyo/vgc-daily-tracker/security/advisories/new),
with the steps to reproduce it and what it affects.

## Scope

VGC Daily Tracker keeps all data on the device and has no accounts or
server. It only calls the public [PokéAPI](https://pokeapi.co) over HTTPS
and needs no API keys. Only the latest version on `main` is supported.
